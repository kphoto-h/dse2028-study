設定與帳戶

登入後可把個人紀錄同步到自己的帳戶。

G
Google 登入

每位使用者的紀錄分開儲存，不會混在一起。

需要先設定 Firebase 才能啟用登入。
個人目標
啟用 Google 登入（Firebase 免費方案）
  1. 到 Firebase Console 建立免費專案。
  2. 新增 Web App，複製 Firebase config，填入本檔案底部的 firebaseConfig。
  3. Authentication → Sign-in method → 啟用 Google。
  4. 建立 Firestore Database。
  5. Authentication → Settings → Authorized domains，加入你的 GitHub Pages 網域。
  6. Firestore Rules 使用以下規則，讓使用者只能存取自己的資料。
rules_version = '2';
service cloud.firestore {
 match /databases/{database}/documents {
  match /users/{userId}/appData/{docId} {
   allow read, write: if request.auth != null
                      && request.auth.uid == userId;
  }
 }
}
GitHub Pages 是靜態網站，不能只靠 HTML 完成真正帳戶驗證。Google 登入及雲端同步需要 Firebase 設定。Firebase config 的前端識別資料不是私密金鑰；不要把服務帳戶私鑰放入網站。
